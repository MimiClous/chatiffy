# Zakviel Chat Overlay

Локальный оверлей Twitch-чата для OBS. По умолчанию подключается к каналу `zakvielchannel`, показывает бейджи пользователей, нативные Twitch-эмоуты и глобальные/канальные 7TV-эмоуты, включая анимированные WebP.

## Запуск на сервере

Требуется Node.js 20 или новее. Устанавливать npm-пакеты не нужно.

```bash
unzip zakvielchat-server.zip
cd zakvielchat
npm start
```

По умолчанию страница откроется на `http://IP_СЕРВЕРА:8080`. Порт можно изменить:

```bash
PORT=3000 npm start
```

Для постоянной работы рекомендуется запускать приложение через systemd, Docker или процесс-менеджер.

### Docker

```bash
docker build -t zakvielchat .
docker run -d --restart unless-stopped -p 8080:8080 --name zakvielchat zakvielchat
```

После этого в OBS укажите URL `http://IP_СЕРВЕРА:8080`.

## Запуск в OBS

1. Добавьте источник **Браузер**.
2. Включите **Локальный файл**.
3. Выберите `index.html` из этой папки.
4. Укажите размер, например 600 × 900.
5. Рекомендуется включить «Обновлять браузер, когда сцена становится активной».

Страница прозрачная. Наведитесь на правый верхний угол и нажмите ⚙, чтобы сменить канал, размер текста, время жизни и число сообщений. Настройки сохраняются на этом компьютере.

## Параметры URL

Если оверлей раздаётся веб-сервером, настройки можно передать в URL:

`index.html?channel=zakvielchannel&size=28&lifetime=35&max=40&background=1&theme=glass&align=left`

- `lifetime=0` — не удалять старые сообщения по таймеру.
- `background=0` — убрать тёмную подложку.
- `theme=glass`, `clean` или `neon` — оформление сообщений.
- `align=left` или `right` — сторона выравнивания.

## Важно

- Twitch-токен не нужен: используется анонимное чтение публичного чата.
- Для `zakvielchannel` Twitch ID встроен в оверлей, поэтому загрузка его 7TV-набора не зависит от стороннего преобразователя имени.
- Для работы нужны доступ к Twitch, 7TV и их CDN.
- Если OBS не даёт сетевой доступ локальному файлу, раздайте папку любым статическим сервером и укажите HTTP-адрес в источнике «Браузер».

## Структура

- `index.html`, `style.css`, `app.js` — сам оверлей.
- `server.mjs` — статический HTTP-сервер без внешних зависимостей.
- `Dockerfile` — запуск в контейнере.
- `start.sh` и `start.bat` — быстрый запуск на Linux и Windows.
