Windows 10/11 x64: распакуйте ZIP целиком и запустите **Chatiffy.exe**. Требуется .NET Framework 4.8; Node.js включён.

### Chatiffy 1.4.6

- Вместо раскрывающихся списков — вкладки «Канал», «Оформление», «OBS», «Профили», «Приложение».
- Настройки остаются внутри рабочей области, без наложения меню и увеличения страницы. Предпросмотр расположен справа; на узких экранах используется одна внутренняя прокрутка.
- Компактный переключатель профилей в шапке. Профили больше не называются сценами.
- Исправлено выделение выбранного готового стиля, поведение кнопок сохранения и проверки обновлений.
- Проверенные картинки демо-эмоутов, включая Aware, включены в приложение; исправлен приоритет канальных 7TV-эмоутов.
- Сплэш вписан в шапку, подчёркивание в chatiffy_ мигает как курсор.
- Исправлены цвета текста, подменю и галочки автозагрузки в Windows-трее.

### Chatiffy 1.4.5 — общий выпуск

Объединяет серию 1.4.2 и её промежуточные выпуски 1.4.3–1.4.4, а также последующие исправления. Старые Git-теги сохранены для истории; отдельные релизы серии заменены этим выпуском.

- Полный глобальный и канальный каталог Twitch-бейджей без обязательной настройки OAuth; актуальные выбранные бейджи оригинальных аккаунтов в предпросмотре.
- Исправления 7TV-окраски и эмоутов. Картинки демо-эмоутов включены в приложение, включая Aware; канальные эмоуты имеют приоритет над глобальными.
- Живая пародийная переписка всех 30 участников со стройкой и загадочными Хранителями.
- Компактный редактор: шаги 1–2–3 слева, предпросмотр справа, дополнительные настройки поверх рабочего пространства.
- Профили вместо сцен: переключатель в шапке, управление в свёрнутом меню. Исправлено выделение готовых стилей.
- Сплэш встроен в шапку, курсор в chatiffy_ мигает. В README — GIF с котом у клавиатуры.
- Размеры предпросмотра отделены от размеров источника, которые задаются вручную в OBS.
- Исправлены цвета меню трея и подменю. Добавлен переключатель автозагрузки Windows.
- Исправлено чтение SHA-256 в Windows PowerShell. Проверка обновлений по кнопке запрашивает свежий релиз.

**Обновление с 1.4.0–1.4.3:** при Invalid release checksum file один раз завершите Chatiffy через трей и распакуйте полный ZIP 1.4.5 с заменой файлов. Профили сохранятся. После этого можно пользоваться автообновлением.

### Новое в 1.4.1

- Живой предпросмотр: 35 реплик с пародийными никами участников Майншилда и общением друг с другом.
- Сообщения поступают постепенно и вытесняют старые по лимиту профиля; оформление меняется без очистки переписки.
- Анимированный 7TV kekBomb у PWGod; пауза демонстрации и поддержка таймера скрытия.
- Исправлена документация выпуска.

### Новое в 1.4.0

- Порт по умолчанию **17845**. После старой версии один раз замените адрес источника OBS.
- Постоянные ссылки профилей: изменения сохраняются автоматически и появляются в OBS примерно через 3 секунды.
- Именованные сцены, переключение, создание копий и экспорт/импорт профилей в JSON.
- Обычный и вертикальный предпросмотр с точными размерами источника OBS, краткая инструкция первого запуска.
- Случайный пиксельный сплэш при открытии страницы.
- Предпросмотр сообщений, понятные группы настроек, готовые стили, сброс оформления, переключатель скрытия по таймеру.
- Выбор шрифта, жирности, курсива и интервалов.
- Проверка обновлений в редакторе и трее; установка проверенного ZIP с резервной копией и сохранением профилей.
- Диагностика сервера и упрощённое меню трея.
- TypeScript, расширяемые модули и подробная документация в docs/.

Для первой установки этой версии выйдите из старого приложения и распакуйте весь архив. Старый лаунчер ещё не поддерживает обновление кнопкой.
Приложение не подписано цифровой подписью. Тестовые сборки доступны отдельно в GitHub Actions.
