Windows 10/11 x64: распакуйте ZIP целиком и запустите **Chatiffy.exe**.
Docker и установка Node.js не требуются. Редактор: http://127.0.0.1:8080.

- Нативное приложение в трее без встроенного браузера.
- Открытие редактора, настройки Twitch, журнал, перезапуск и выход через меню трея.
- Один экземпляр; локальный сервер завершается вместе с приложением, в том числе при аварии.
- Ключи Twitch необязательны; настройки сохраняются в `%LOCALAPPDATA%\Chatiffy`.
- Официальный Node.js 24.22.1 включён в архив; контрольная сумма ZIP приложена.

Порт 8080 должен быть свободен. Приложение не подписано цифровой подписью.
Для обновления сначала завершите предыдущую версию через меню трея.
