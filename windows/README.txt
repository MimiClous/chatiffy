Chatiffy для Windows 10/11 x64

Распакуйте весь архив в постоянную папку и запустите Chatiffy.exe.
Docker, установка Node.js и права администратора не нужны.
Используется встроенный в Windows .NET Framework 4.8.

Приложение находится в трее (возможно, под стрелкой скрытых значков).
Двойной щелчок открывает редактор http://127.0.0.1:8080.
Скопируйте ссылку из редактора в источник «Браузер» OBS.
Закрытие браузера не останавливает сервер. Меню «Выход» останавливает его.
Повторный запуск не создаёт второй сервер. Chatiffy.exe --quit завершает приложение.
Сервер слушает только 127.0.0.1, порт 8080; доступ из сети закрыт.
Если порт занят, освободите его и выберите «Перезапустить сервер».

Ключи Twitch необязательны. Откройте «Настройки Twitch», заполните значения,
сохраните файл и перезапустите сервер из трея. Настройки и журнал находятся
в %LOCALAPPDATA%\Chatiffy. Не передавайте settings.env другим людям.
Параметры HOST/PORT/ALLOWED_HOSTS закреплены лаунчером для локального запуска.
Журнал ограничен примерно 2 МБ (текущий и предыдущий файл).

Для автозапуска по желанию: Win+R → shell:startup и поместите туда ярлык
Chatiffy.exe. Для обновления выйдите из приложения и распакуйте новый архив;
настройки сохранятся. Для удаления выйдите и удалите папку приложения,
ярлык автозапуска и при необходимости %LOCALAPPDATA%\Chatiffy.

Приложение не содержит встроенного браузера; оверлей рендерит OBS.
Бинарный файл не подписан цифровой подписью; Windows может показать SmartScreen.
