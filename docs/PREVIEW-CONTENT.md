# Содержимое демо-чата

Предпросмотр — вымышленная переписка, а не трансляция сообщений реальных аккаунтов.
Состав сверяется с [официальным списком участников](https://mineshield.gg/members)
(30 участников, проверено 27 октября 2026 года). Искажённые ники всех участников
перечислены в `src/client/demo-roster.ts`; тип DemoNickname не позволяет случайно
добавить в переписку посторонний ник. В демонстрацию входят все 30 участников списка.
Нео и Кролик, которых нет на предоставленной странице, из этой подборки убраны.

Короткие узнаваемые цитаты и мемы перемешаны с написанными для демонстрации ответами.
Сочинённые ответы служат для проверки переноса строк, упоминаний, цвета и темпа чата
и не выдаются за дословные высказывания стримеров.

  [Shield Awards, номинации мемов и цитат](https://mineshield.fandom.com/ru/wiki/Shield_Awards).

Публичная вики — вторичный источник сообщества; таймкоды всех оригинальных стримов
не проверены. Новые «дословные цитаты» без источника сюда не добавляются.

## kekBomb

Эмоут найден в публичном 7TV-наборе PWGood:
[набор 61c802080bf6300371940381](https://7tv.io/v3/emote-sets/61c802080bf6300371940381).
ID: `01FAKB7TWR0002EV4FV333ASYK`, анимированный `2x.webp` с CDN 7TV.
Из того же набора проверены Aware, monka, sus, Panic и PagMan. Каждый из этих пяти
эмоутов появляется один раз в сюжетной вставке; kekBomb остаётся основной реакцией PWGod.
Первые 153 реплики сохраняют исходную историю стройки. Затем начинается вымышленная
сцена «ОНИ ПРИШЛИ»: Хранители как загадочные глаза в небе наблюдают за участниками.
Герои пытаются продолжать стройку, глаза исчезают, но остаются тень и знак на крыше,
которой ещё не было. Хранители не получают бытового объяснения; шутки принадлежат
участникам переписки. Это художественная демо-сцена, а не цитаты реального стрима.
Предпросмотр использует отдельный маленький каталог эмоутов: рендер тот же,
но он не зависит от подключения к Twitch и выбранного реального канала.
При ошибке изображения возвращается текст `kekBomb`.

Переписка содержит 256 реплик. Первые пять видны сразу, следующие приходят с паузами
1.4–3.1 секунды; после конца последовательность повторяется. Лимит сообщений берётся
из профиля; старейшие строки удаляются. Изменение оформления не очищает переписку.
Пауза и скрытая вкладка останавливают демонстрационное время и появление новых строк.

## Бейджи оригинальных аккаунтов

Искажённый ник остаётся отображаемым именем. Внутренний Twitch ID и логин берутся
из `src/client/demo-identities.ts`: официальная страница каждого участника содержит
ссылку на его Twitch. Снимок публичных displayBadges и подтверждённого статуса партнёра
получен непосредственно из Twitch; бейджи не назначаются случайно.
Бейджи и окраска 7TV загружаются существующим локальным API по ID и логину оригинала.
При недоступности 7TV остаются Twitch-бейджи из сохранённого снимка.
Если у аккаунта нет публичного бейджа, для него не рисуется выдуманный значок.

Обновление снимка: `node scripts/update-demo-identities.mjs` (Node 20+, нужен интернет).
Скрипт проверяет все 30 аккаунтов и записывает файл только после успешной сверки;
его не требуется запускать при старте приложения. Публичный Twitch GraphQL API
может менять схему; при сбое снимок предыдущего успешного запуска сохраняется.
Запросы не требуют входа в Twitch, токена пользователя или подключения к чату.
VIP, модератор, подписка и основатель зависят от канала и в демо не выдумываются.
Реальный OBS-чат продолжает брать их из IRC-тегов входящих сообщений.
